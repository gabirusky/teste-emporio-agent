## Project Overview

The goal of this project is to build a Python-based text agent that supports the customer service team of Empório da Música, a fictional musical instrument retailer based in Campo Grande, Brazil.

The store receives a message with questions about product availability, prices, order status, delivery, payment methods, and return policies.

The proposed agent handles these requests through a conversational interface while consulting the appropriate source of information before answering.

The language model should understand and communicate with the appropriate store persona, while application tools remain responsible for retrieving business facts. The model should never guess the real data, always use tools and data available.

The customer-facing persona follows the store manual: friendly, informal, professional, and knowledgeable about musical instruments. 

The prototype's customer interaction is configured for Brazilian Portuguese, matching the store's Brazilian audience. This technical submission is written in English as requested in the recruitment instructions.
